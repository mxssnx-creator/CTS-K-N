# Interrupted x02 lifecycle study and durable recovery checkpoints

The twelve-symbol native VST study was incomplete. Ten cycles finished with `flat=true`; the executor disappeared after the eleventh symbol's first entry. Its original process session was unavailable, the log and isolated Redis snapshot stopped changing, and no final native report was written. The termination cause is unknown. This is not a passed twelve-symbol test or a strategy-profitability result.

Independent recovery read the exact acknowledged COTI entry ID and its unique run identity, verified its 243 filled units against current same-side exposure and the run's venue history, and required an empty symbol order book before dispatch. One durable recovery close sold exactly those 243 units. Its filled receipt was read again, followed by an empty same-side position and order book. No whole-position close, foreign cancellation or account flatten was used.

Subsequent reconciliation bound all 62 acknowledged run/recovery IDs to venue history: all were terminal, no own orders remained, and signed opening/closing quantities netted to zero on every tested side. Eleven distinct symbols had own fills: ten completed native cycles and one recovery cycle. The twelfth symbol was not executed. Other account systems were active, so strict restoration of the complete account baseline is not asserted.

The harness previously wrote its report only on preflight failure or in `finally`. A killed executor could therefore lose its recoverable run manifest despite durable production order controls in its isolated Redis snapshot. It now atomically writes a private, fsynced recovery checkpoint before every venue dispatch and after each response/error. The checkpoint includes its exact run ID, Redis snapshot path, acknowledged own exposure/control/order IDs, cycle progress and redacted write identities. Pending writes remain potentially ambiguous; an HTTP response does not itself prove an accepted exchange order. Running checkpoints explicitly remain incomplete and do not get a `finishedAt` timestamp.

Snapshots are replaced atomically at mode 0600. A redaction failure preserves the last valid report and refuses dispatch. Request evidence whitelists order fields and keeps query/body identities separate; signed URLs, headers and authentication fields are excluded. This change does not automatically resume an interrupted financed lifecycle or infer ownership from the account balance.
